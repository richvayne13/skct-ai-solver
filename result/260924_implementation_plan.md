## 1. 프로젝트 개요 및 목적
* **목적**: 스마트폰 카메라를 통해 인적성/적성검사 문제(수리, 추리, 언어 등)를 비추면, 별도의 셔터 버튼을 누르지 않아도 문제 영역을 자동으로 인식하고, AI 비전 모델이 문제를 신속하게 풀이하여 **정답 번호와 핵심 풀이를 한눈에 크게 표시**해 주는 학습 보조 모바일 애플리케이션 개발.
* **핵심 기능 요구사항**:
  1. **무터치 자동 문제 인식**: 카메라 프리뷰 상태에서 화면 내 문제 영역을 감지하거나 고정 상태(움직임 멈춤)를 감지하여 자동으로 캡처 및 AI 분석 요청.
  2. **AI 기반 문제 풀이 및 정답 도출**: 수식, 표, 벤다이어그램, 명제 기호 등을 인식하여 가장 타당한 정답 번호 및 요약 해설 생성.
  3. **시인성 높은 UI/UX**: 정답 번호를 화면에 초대형 텍스트로 즉각 표출.
  4. **원터치 다음 문제 전환**: 화면의 아무 곳이나 터치하면 즉시 다음 문제를 인식할 수 있도록 리셋.

## 2. 권장 기술 스택 및 구조 검토

### [방안 A] 모바일 최적화 웹앱 (PWA / HTML5 + FastApi/Python 백엔드) - ⭐ 가장 추천
* **구조**:
  - **프론트엔드**: 스마트폰 모바일 브라우저(Chrome/Samsung Internet)에서 접속 가능한 PWA 웹앱.
    - `MediaDevices.getUserMedia`를 통한 실시간 카메라 영상 취득.
    - Canvas 기반 화면 모션 감지(움직임 멈춤 감지 시 자동 캡처) 및 영역 가이드라인.
  - **백엔드 (`tool/server`)**: Python FastAPI / Flask 서버.
    - 이미지 전처리(대비/기울기 보정) 후 멀티모달 AI(Google Gemini Flash 등) API 호출.
* **장점**:
  - PC에 복잡한 Android Studio, Android SDK, Gradle 빌드 환경 설치 불필요.
  - 스마트폰과 PC가 동일 Wi-Fi에 연결되어 있으면 즉시 스마트폰 카메라로 테스트 및 구동 가능.
  - 개발 및 수정 속도가 압도적으로 빠름.

### [방안 B] 네이티브 안드로이드 앱 (Kotlin / Android Studio)
* **구조**: CameraX + Retrofit2/OkHttp + Android Jetpack Compose / XML.
* **장점**: 온디바이스 네이티브 카메라 제어의 유연성.
* **단점**: PC 환경에 Android 개발 툴체인이 갖추어져 있어야 하며 빌드/설치(APK) 과정이 수반됨.

## 3. 핵심 기능별 세부 설계 아이디어

### ① "버튼을 누르지 않는 문제 영역 인식" 알고리즘
1. **화면 프레임 가이드**: 카메라 중앙에 직사각형 문제 영역 가이드라인 오버레이 표시.
2. **모션 디텍션 (안정화 감지)**:
   - 카메라가 모니터/문제집을 비추고 손이 흔들리다가 멈추는 순간(프레임 간 차이값이 일정 임계치 이하로 1~1.5초 유지될 때) 자동 캡처 트리거.
   - 또는 OpenCV 기반의 문서 윤곽선(Contour) 자동 감지.

### ② AI 문제 해결 파이프라인
* **비전 멀티모달 AI 활용 (Gemini 2.0 / 1.5 Flash)**:
  - 이미지 OCR과 문제 추론을 한 번에 수행하여 응답 속도 극대화 (1~2초 내 정답 도출).
  - 프롬프트 엔지니어링: "반드시 정답 번호(예: ③)를 가장 첫 줄에 큰 글자로 출력하고, 그 아래 2줄 이내로 핵심 이유/공식을 출력할 것".

### ③ UI 구성
* **대기 모드**: 카메라 화면 + 직사각형 문제 인식 박스 + "문제를 박스 안에 맞추면 자동으로 인식합니다" 안내.
* **분석 중**: 가벼운 로딩 인디케이터.
* **결과 표시**:
  - 화면 중앙 상단: **초대형 정답 번호 (예: 4번)** (배경색 초록/파랑 강조)
  - 중간: **핵심 풀이 요약 (1~2줄)**
  - 하단 전체: **[화면을 터치하면 다음 문제]** 대형 버튼 영역.
