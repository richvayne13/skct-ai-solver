# [SKCT AI 고속 풀이 솔루션] 고도화 및 오답노트 연동 구현 계획서

- **작성일자**: 2026-09-24
- **작성자**: Antigravity
- **대상 프로젝트**: `skct-ai-solver` & `skct-notes`
- **목표**: 실전 SKCT 시험 대비 속도/정확도 극대화, 영역별 특화 모드 제공, 푼 문제의 오답노트 원클릭 연동 지원

---

## 1. 추진 배경 및 개선 필요 사항

1. **실행 환경 의존성 완비 필요**:
   - `fastapi`, `uvicorn`, `httpx`, `cryptography`, `python-dotenv` 등 핵심 라이브러리 설치 필요.
2. **AI 풀이 정확도 및 추론력 선택 지원**:
   - 현재 `gemini-2.0-flash` 단일 설정 $\to$ 빠른 초고속 모드(`gemini-2.0-flash`)와 고난도 심층 추론 모드(`gemini-2.5-flash` / `gemini-2.0-flash-thinking` / `gemini-1.5-pro`)를 설정에서 선택할 수 있도록 개선.
3. **SKCT 5대 영역별 맞춤 프롬프트 선택**:
   - 수리(방정식/소금물/확률), 수열(계차/군수열), 자료해석(표/그래프/가평균), 언어추리(명제/조건배치) 등 상단 원터치 필터를 통해 AI의 분석 정확도 대폭 상향.
4. **상세 단계별 해설(Step-by-step) 토글 기능**:
   - 기본은 초대형 정답 번호와 1줄 핵심 근거를 표시하되, 사용자가 원할 때 탭하여 "상세 풀이 과정"을 즉시 펼쳐볼 수 있도록 지원.
5. **문제 형태별 뷰파인더(가이드 박스) 종횡비 조절**:
   - 표/차트 등 가로로 긴 문제(자료해석)와 세로로 긴 문제(언어 지문)를 편하게 맞출 수 있도록 [가로형 / 표준 / 세로형] 뷰파인더 원터치 전환 버튼 제공.
6. **`skct-notes` (오답노트) 원클릭 연동 저장**:
   - 푼 문제를 화면 터치 한 번으로 `skct-notes` 포맷으로 내보내거나 로컬 오답 리스트에 자동 저장하여 사후 복습 연계.

---

## 2. 세부 구현 계획

### [단계 1] 백엔드(`server.py`) 고도화
- **모델 동적 선택**: 클라이언트 요청 및 서버 설정에서 `model` 파라미터 지원 (`gemini-2.0-flash`, `gemini-2.5-flash`, `gemini-1.5-pro` 등).
- **영역별 특화 프롬프트 분기**: `category` (all, math, series, data, logic, verbal) 전달 시 특화 가이드 주입.
- **출력 포맷 표준화**:
  - 1행: `정답: X번 (X)`
  - 2행: `핵심: [1줄 결정적 풀이/공식]`
  - 3행 이후: `상세풀이: [단계별 풀이 과정]`
- **오답노트 저장 API**: `/api/notes/save` 엔드포인트를 제공하여 캡처된 문제 이미지와 AI 풀이를 `skct-notes` 호환 JSON으로 보관/내보내기 지원.

### [단계 2] 프론트엔드(`index.html`, `style.css`, `app.js`) UI/UX 강화
- **상단 퀵 영역 필터**: [전체] [수리] [수열] [자료해석] [명제/조건] 탭 버튼 추가.
- **뷰파인더 비율 토글**: [가로형(4:3)] [표준(1:1)] [세로형(3:4)] 토글 버튼 추가.
- **상세 풀이 토글 뷰**: 초대형 정답 화면 하단에 `[📖 상세 풀이 보기]` 버튼 추가, 탭 시 슬라이드업 모달로 단계별 풀이 확인.
- **오답노트 원클릭 저장 버튼**: `[💾 오답노트 저장]` 버튼 클릭 시 로컬 스토리지 및 서버에 즉시 보관.
- **설정 모달 확장**: AI 모델 선택 드롭다운, 영역별 기본 설정 지원.

### [단계 3] 오답노트(`skct-notes`)와의 연동 브릿지
- `skct-ai-solver`에서 저장한 문제들을 `skct-notes`의 `data/` 형식에 맞추어 바로 가져오기(Import)할 수 있는 JSON 내보내기/불러오기 호환 기능 완성.

### [단계 4] 검증 및 테스트
- 의존성 설치 확인 및 SSL 인증서 기반 로컬 서버 실행.
- 모바일 화면 레이아웃 및 API 통신 검증.
- 최종 결과 보고서(`result/260924_result_report.md` 갱신) 작성.
