# 개발자가 사용하는 프론트엔드 UI 핵심 용어 사전

작성일: 2026-09-25  
작성자: Antigravity Assistant  
연동 위치: Microsoft OneNote (`개발노트` 전자필기장 > `프론트엔드 UI 용어` 섹션)

---

## 📌 1. 상태 변경 및 입력 컨트롤 (Selection & Input)

* **토글(Toggle) / 스위치(Switch)**
  * **설명**: 스마트폰 설정에서 Wi-Fi/블루투스를 켜고 끌 때 좌우로 딸깍 움직이는 스위치 버튼.
  * **용도**: ON/OFF, 적용/비적용, 다크모드 켜기/끄기처럼 2가지 상태를 즉시 전환할 때 사용.
* **체크박스(Checkbox) vs 라디오 버튼(Radio Button)**
  * **체크박스 (네모 상자 ☑)**: 여러 개를 동시에 선택할 수 있는 다중 선택 컨트롤.
  * **라디오 버튼 (동그란 원 ⦿)**: 여러 옵션 중 오직 하나만 골라야 하는 단일 선택 컨트롤.
* **드롭다운(Dropdown) / 셀렉트박스(Select Box)**
  * **설명**: 클릭하면 아래로 목록이 펼쳐지고 그중 하나를 선택하는 박스. (예: 출생년도 선택)
* **세그먼트 컨트롤(Segmented Control)**
  * **설명**: `[일간 | 주간 | 월간]`처럼 여러 선택지가 하나의 가로 막대로 묶여있는 버튼 그룹.

---

## 🖐️ 2. 제스처 및 조작 인터랙션 (Interactions & Gestures)

* **드래그 앤 드롭(Drag & Drop / DnD)**
  * **설명**: 마우스나 터치로 요소를 꾹 눌러 끌고 가서 원하는 위치에 놓는 조작. (파일 첨부, 순서 변경)
* **인피니트 스크롤(Infinite Scroll) vs 페이지네이션(Pagination)**
  * **인피니트 스크롤**: 인스타그램, 유튜브 피드처럼 스크롤을 내리면 다음 컨텐츠가 끊임없이 자동 로딩되는 방식.
  * **페이지네이션**: `[1] [2] [3] ... [다음]` 처럼 하단에 페이지 번호가 매겨져 있는 방식.
* **풀 투 리프레시(Pull-to-Refresh)**
  * **설명**: 모바일 앱에서 화면 맨 위를 아래로 당겼다 놓으면 새로고침되는 제스처.
* **스와이프(Swipe)**
  * **설명**: 화면을 좌우로 쓱 넘기는 제스처. (사진 넘겨보기, 탭 전환)

---

## 🪟 3. 팝업 및 알림 계열 (Overlays & Feedback)

* **모달(Modal) / 다이얼로그(Dialog)**
  * **설명**: 화면 한가운데에 툭 튀어나오며 **뒷배경이 어둡게(Dim) 차단**되어 확인/취소를 누르기 전까지 뒤 화면을 조작할 수 없는 집중형 팝업창.
  * **용도**: 중요한 결정(탈퇴, 삭제, 결제 확인 등)을 유도할 때 사용.
* **토스트(Toast) / 스낵바(Snackbar)**
  * **설명**: 화면 하단에 2~3초간 "복사되었습니다"처럼 떴다가 사라지는 가벼운 안내 메시지. (사용자 흐름 방해 안 함)
* **바텀시트(Bottom Sheet)**
  * **설명**: 모바일 앱에서 아래에서 반쯤 스르륵 올라오는 옵션 메뉴 창. (카카오택시 목적지 설정, 배민 결제창)
* **드로어(Drawer) / 사이드바(Sidebar)**
  * **설명**: 화면 좌우에서 서랍 열리듯 쓱 슬라이드되어 나오는 메뉴 패널. (햄버거 버튼 누르면 나오는 창)
* **툴팁(Tooltip)**
  * **설명**: 마우스를 올렸을 때(Hover) 물음표나 버튼 옆에 작게 말풍선으로 뜨는 도움말.

---

## 📱 4. 화면 구성 및 레이아웃 (Layout & Display)

* **캐러셀(Carousel) / 슬라이더(Slider)**
  * **설명**: 회전목마처럼 여러 배너나 이미지가 좌우로 자동으로 넘어가거나 슬라이드되는 영역.
* **아코디언(Accordion)**
  * **설명**: FAQ처럼 제목을 누르면 아래로 내용이 쫙 펼쳐지고 다시 누르면 접히는 접이식 UI.
* **스켈레톤 UI(Skeleton Screen)**
  * **설명**: 데이터 로딩 중 뼈대(회색 박스)가 깜빡이며 로딩 중임을 미리 보여주는 UI. (유튜브 로딩 창)
* **뱃지(Badge)**
  * **설명**: 카카오톡 앱 옆 빨간 숫자(1)나 메뉴 옆 `[NEW]`처럼 시각적으로 강조하는 작은 원형/태그.
* **플로팅 액션 버튼(FAB, Floating Action Button)**
  * **설명**: 스크롤해도 화면 우측 하단 공중에 둥둥 떠 있는 원형 액션 버튼. (당근 글쓰기 버튼)

---

## 🍔 5. 햄버거 메뉴와 음식 아이콘 4총사

* **햄버거 (☰)**: 빵-패티-빵 모양 (가로 3줄). 누르면 전체 사이드 메뉴(사이드바/드로어)가 열림.
* **미트볼 / 도트 (···)**: 고기 완자 모양 (가로 점 3개). 더보기, 공유, 수정/삭제 옵션.
* **케밥 (⋮)**: 꼬치 모양 (세로 점 3개). 유튜브 영상 우측 더보기 메뉴.
* **벤토 (⠃⠃ / 9개 격자)**: 도시락통 모양. 구글 메인 우측 상단 "구글 앱 모음" 아이콘.

## 💬 6. 개발자와 대화할 때 쓰는 실전 대화 예시

1. *"다크모드 전환은 스위치 형태로 토글되게 해주세요."*
2. *"목록 순서는 드래그 앤 드롭으로 바꿀 수 있게 구현해주세요."*
3. *"저장 완료 시 귀찮은 모달창 대신 하단에 가볍게 토스트 메시지만 띄워주세요."*
4. *"상단 우측 햄버거 버튼 누르면 바텀시트나 드로어로 메뉴가 나오게 해주세요."*
