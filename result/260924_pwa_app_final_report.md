### [2단계] 스마트폰에 '진짜 앱'으로 설치하기
* **안드로이드 (Chrome / Samsung Internet)**:
  - 화면 상단의 핑크색 **`[📲 앱 설치]`** 버튼을 탭하거나, 브라우저 우측 상단 메뉴(점 3개 `⋮`) $\to$ **[앱 설치]** 또는 **[홈 화면에 추가]**를 누릅니다.

### [3단계] 1회 API 키 입력 후 바로 사용
1. 우측 상단 ⚙️ 설정에서 [Google AI Studio](https://aistudio.google.com/app/apikey) 무료 API 키를 1회 입력 및 저장합니다.

2. 문제를 가이드 박스 안에 넣고 1초간 가만히 있으면, 하단 게이지가 차오르며 자동으로 캡처 & AI 분석이 수행됩니다.

4. 화면 아무 곳이나 툭 터치하면 즉시 다음 문제 감지 모드로 리셋됩니다!
