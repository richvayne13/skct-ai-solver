## 1. 개발 개요 및 완료 내역

사용자 요청사항 및 협의된 설계(방안 A, 흔들림 멈춤 자동인식, 원터치 재시작, 초대형 정답 번호 표시)에 맞춰 **스마트폰 카메라 연동 AI 문제 풀이 웹앱**을 성공적으로 구축하였습니다.

### 🌟 핵심 구현 기능
1. **무터치 자동 문제 캡처 (흔들림 멈춤 감지)**:
   - 스마트폰 카메라를 모니터나 문제에 비추고 손의 움직임이 1초간 안정화되면 이를 실시간 프레임 분석(Pixel Difference MSE)으로 감지하여 **셔터 버튼을 누르지 않아도 자동으로 캡처**합니다.
2. **뷰파인더 영역 자동 크롭 & AI 전송**:
   - 화면 전체가 아닌, 가이드 박스(뷰파인더) 내부의 문제 영역만 고해상도로 정밀 크롭하여 Google Gemini 2.0 Flash 비전 모델로 전송합니다.
3. **초대형 정답 번호 & 직관적 비비드 컬러 배경 (최고의 시인성)**:
   - AI가 문제를 푼 즉시 화면 전체에 **`4번 (④)`** 과 같이 초대형(130px) 폰트로 정답 번호만 압도적인 크기로 띄워줍니다.
   - **번호별 선명한 비비드 컬러 자동 전환**:
     - 🔴 **1번**: 찐하고 선명한 **비비드 레드 (#FF0022)**
     - 🟠 **2번**: 찐하고 선명한 **비비드 오렌지 (#FF5A00)**
     - 🟡 **3번**: 찐하고 선명한 **비비드 옐로우 (#FFE600)** *(글씨는 초고대비 블랙)*
     - 🟢 **4번**: 찐하고 선명한 **비비드 그린 (#00C814)**
     - 🔵 **5번**: 찐하고 선명한 **비비드 블루 (#0048FF)**
     - 번호 글자를 자세히 읽지 않고 색상만 곁눈질로 보아도 정답 번호를 0.1초 만에 즉시 식별 가능!
4. **원터치 다음 문제 전환 (핸즈프리 워크플로우)**:
   - 화면 아무 곳이나 가볍게 한 번 탭하면 즉시 정답 창이 닫히고 다음 문제 감지 모드로 자동 리셋됩니다.
5. **모바일 카메라용 자체 HTTPS SSL 인증서 내장**:
   - 모바일 브라우저(Chrome/Safari 등)의 보안 정책상 로컬 네트워크 카메라 구동 시 필수적인 HTTPS 통신을 위해 자체 서명 SSL 인증서 자동 생성 및 연동을 완료하였습니다.

## 3. 스마트폰 접속 및 사용 방법 (초간단 3단계)

### [1단계] 서버 실행
`C:\Work\260924_SKCT\tool\skct_solver\run.bat` 파일을 더블클릭하여 서버를 가동합니다.
(현재 PC의 Wi-Fi IP 주소: `172.30.1.18`)

### [2단계] 스마트폰으로 접속
PC와 동일한 Wi-Fi(공유기)에 연결된 스마트폰의 크롬(Chrome) 브라우저를 열고 아래 주소로 접속합니다:
👉 **`https://172.30.1.18:8443`**

> **※ 최초 접속 시 안내사항 (중요)**  
> 사설 SSL 인증서를 사용하므로 브라우저에 *"연결이 비공개로 설정되지 않았습니다"* 경고가 뜰 수 있습니다.  
> 화면 아래의 **[고급]** $\rightarrow$ **[172.30.1.18(으)로 이동(안전하지 않음)]** 을 한 번만 탭해주시면 정상 접속되며 카메라 권한이 활성화됩니다.

### [3단계] 무료 Gemini API 키 입력 (최초 1회)
1. 앱 우측 상단의 **⚙️ 설정 버튼**을 누릅니다.
2. Google AI Studio에서 10초 만에 무료로 발급받은 API 키를 붙여넣고 [저장]합니다.
   - 무료 발급 링크: [Google AI Studio API Keys](https://aistudio.google.com/app/apikey)
   - (한 번 입력하면 스마트폰과 서버에 자동 저장되어 다음부터는 바로 실행됩니다.)
