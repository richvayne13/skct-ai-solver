## 2. 🌟 주요 신규 기능 및 고도화 내역

### 1) SKCT 5대 핵심 영역별 특화 가이드 주입
* 상단 카테고리 칩: **[⚡ 종합] [🧮 창의수리] [🔢 수열추리] [📊 자료해석] [🧩 명제/조건] [📖 언어이해]**
* 각 영역 선택 시, AI 모델에게 해당 영역의 핵심 전략(소금물/거속시/일률 공식, 계차/군수열/피보나치 패턴, 표/차트 머리말·단위·각주·가평균 십자곱셈, 대우명제·삼단논법·조건 표 배치 등)을 정밀 주입하여 **오답률을 최소화하고 풀이 속도를 극대화**합니다.

### 2) 뷰파인더(가이드 박스) 종횡비 3단 원터치 전환
* 문제 유형에 따라 상단 `[📐 뷰파인더]` 버튼을 탭하여 즉시 전환:
  - **표준 (1:1 / 기본)**: 일반적인 객관식 문제용
  - **가로형 (90% × 38%)**: 표나 복합 차트가 포함된 자료해석 문제용
  - **세로형 (80% × 66%)**: 긴 지문이나 보기가 길게 늘어진 언어/조건추리 문제용

### 3) 3단 체계 응답 파싱 및 [📖 단계별 상세 풀이 모달]
* 기존의 초대형 정답 번호와 1줄 핵심 근거 외에, AI가 백그라운드에서 **문제 분석 $\to$ 수식/논리 전개 $\to$ 정답 도출**의 상세 풀이 과정을 함께 생성합니다.
* 결과 화면에서 `[📖 상세 풀이 보기]` 버튼을 누르면 하단에서 슬라이드업되는 모달을 통해 단계별 해설을 자세히 확인할 수 있습니다.

### 4) `skct-notes`(오답노트) 완벽 연동 & 원클릭 저장
* 결과 화면 또는 상세 풀이 화면에서 `[💾 오답노트 저장]` 버튼을 누르면, 현재 캡처된 문제 이미지와 AI 도출 정답, 핵심 이유, 상세 해설이 서버와 로컬에 즉시 안전하게 보관됩니다.
* 상단 `[📋 오답노트]` 버튼을 누르면 지금까지 저장된 오답 목록을 썸네일과 함께 확인 가능합니다.
* **`skct-notes` 100% 호환 JSON 내보내기**: `[📥 skct-notes 호환 JSON 다운로드]` 버튼을 누르면 `skct-notes` 웹앱의 복원 기능에서 곧바로 불러올 수 있는 표준 JSON 파일로 다운로드됩니다.

### 5) AI 추론 엔진 모델 동적 선택 지원
* 설정(⚙️) 창에서 풀이 목적에 따라 원하는 모델을 손쉽게 변경:

`tool\skct_solver\run.bat` 파일을 더블클릭하여 서버를 가동합니다.
(또는 PowerShell/CMD에서 `python server.py` 실행)

### [2단계] 동일 Wi-Fi 스마트폰에서 접속
스마트폰 브라우저(Chrome 추천)를 열고 다음 주소로 접속합니다:
👉 **`https://192.168.1.103:8443`**

> **※ 사설 SSL 보안 경고 1회 허용**:
> 브라우저에 *"연결이 비공개로 설정되지 않았습니다"* 경고가 뜨면,
> 화면 하단의 **[고급]** $\to$ **[192.168.1.103(으)로 이동 (안전하지 않음)]** 을 탭하면 카메라 권한이 열리고 정상 접속됩니다.

### [3단계] 무료 Gemini API 키 입력
우측 상단 ⚙️ 설정에서 [Google AI Studio](https://aistudio.google.com/app/apikey) 무료 API 키를 1회 입력 및 저장합니다.
